# BlockWorld

Небольшой браузерный игровой хаб в стиле блочных игровых платформ.

## Файлы
- `index.html` — структура меню и карточек игр.
- `style.css` — оформление для компьютера и телефона.
- `script.js` — поиск, запуск мини-игр, награды и сохранение монет.

## Запуск
Откройте `index.html` в браузере или включите GitHub Pages для ветки `main` и папки `/(root)`.

## Что работает
- Адаптивное главное меню.
- Поиск по каталогу из семи мини-игр.
- Окно запуска игры с интерактивными действиями.
- Монеты за игровые действия, сохранение через localStorage.
- Навигация по разделам и случайный выбор игры.

## Примечание
Это самостоятельный браузерный фан-проект с оригинальным названием BlockWorld. Он не подключается к серверам Roblox и не поддерживает сетевой мультиплеер.
